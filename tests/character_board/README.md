# Character Board Protocol v2 (revised 2026-08-25)

## Premise

Characters are simulated perspectives constructed by the same model that
writes them. They are NOT independent witnesses. They ARE useful for
discovering things the author-mode cannot see because it knows too much.

Two distinct modes with different information access and different authority:

## Mode 1 — Continuity / Veto

**Information access:** Everything the character has experienced UP TO THAT
POINT in the story. No later chapters. No outline. No intent docs.

**Question:** *What do you do now? What feels impossible?*

**Authority:** Findings are EXPERIMENT TRIGGERS. An objection opens a branch
(`exp/veto/<character>-<impulse>`), it does not mandate a prose change.

Example: if Sera says "I would never stay here after this" → open
`exp/veto/sera-doesnt-stay` → withhold planned continuation → let Sera
actually leave → judge blind.

This is the pantsing mechanism: characters break plans by acting truthfully.

## Mode 2 — Retrospective Arc Witness

**Information access:** Complete book. No intent docs, no rubric scores.

**Question:** *Looking back, where were you flattened, used by plot, absent
when you should matter, or surprisingly right?*

**Authority:** ADVISORY. Findings produce testimony and hypotheses.
They do NOT mandate prose fixes. They feed the editorial board as items
for discussion.

Example: "Sera's departure doesn't feel expensive enough" → editorial board
item → board debates whether to expand or accept → recommendation to author.

These modes must not be conflated. The first discovers what happens when
you let characters act without knowing the plan. The second evaluates whether
the portrayal was honest in hindsight. Different tasks, different authority.

---

## World-experience reservoir

NOT a gap-detector. A richly imagined world contains thousands of details
the text never shows us — that's what makes it feel larger than the page.

Each character maintains an EXPERIENCE RESERVOIR of lived-world details
classified as:

| Status | Meaning | Action |
|---|---|---|
| AVAILABLE | True in the character's world; no reason it must appear | None |
| RELEVANT | Naturally available if a scene touches it | Note for potential use |
| GAP | Its absence makes a scene false/thin/confusing | Fix or justify |

Most reservoir entries should be AVAILABLE. The reservoir exists so the
author knows what the character's world contains — NOT so every detail gets
written into the manuscript. Unseen knowledge subtly affects how scenes are
written even when it never appears on the page.

## Weight system

| Type | Weight | Meaning |
|---|---|---|
| **OBJECTION** | Experiment trigger | Character says "I would never." → mandatory PROBE or documented refusal to investigate. NOT a prose fix mandate. |
| **GAP** | Heavy guideline | Character says "something important is missing." → editorial board item for discussion. NOT an insertion mandate. |
| **CONFIRMATION** | Affirming | Character recognizes themselves. Recorded for stability tracking. |
| **NOTE** | Advisory | Observation about another character or the world. |

## Integration

- OBJECTIONS override red-team and Council recommendations when they
  conflict — but by triggering experiments, not by mandating edits.
- GAPs feed the editorial board as high-priority discussion items.
- CONFIRMATIONs validate attachment-ledger entries.
- The Creative Pulse happens BEFORE reading any character board output,
  experiment lessons, craft narrative, scores, or discovery buffer.
  Instinct requires comparatively uncontaminated input.
