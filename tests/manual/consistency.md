# Tests: Consistency

Check chapters against the canon ledger in `src/01-world/canon.md` — the
single source of truth for characters, places, objects, rules, and the
per-chapter reveal log.

- Facts in drafts must match the ledger; contradictions are bugs. If a change
  is intentional, amend the ledger first and log it in `docs/decisions.log`.
- Keji's memory editing skills should remain consistent in scale and method.
- The Archive's rules should stay stable unless there is a deliberate story
  beat that changes them.
- Any changes to the city's physical behavior should follow from its
  narrative architecture.
- Watch the ledger's continuity watchlist for known open issues (duplicate
  titles, ending overlap, repeated beats).
