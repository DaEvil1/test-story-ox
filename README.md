# test-story

A software-style AI fiction project exploring a mind-bending sci-fi story with modern prose and poetic color.

## Project Goals

- Target length: ~10,000 words
- Genre: Mind-bending science fiction
- Style: modern, clear, with experimental poetic touches where it feels natural
- Workflow: world-building → character design → iterative outline → chapter drafts → test/consistency checks
